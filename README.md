# 赵欣然今天喝什么

乌萨奇底纹的饮品随机网页：331 个截图确认的单品、品类筛选、三种随机抽签动效（蹦跳、转圈、开车，可关闭），以及星座乐当天的白羊座运势主题提示。售罄的单品照常参与随机，不单独标记。

## 发布到 GitHub Pages

1. 将本文件夹的内容放到仓库根目录，保留 `.github/workflows/pages.yml`。
2. 在仓库的 **Settings → Pages → Build and deployment → Source** 中选择 **GitHub Actions**。
3. 在 **Actions → Publish drink picker → Run workflow** 手动运行一次，或向默认分支提交更新。
4. 工作流成功后，Pages 设置页与部署记录会显示实际访问网址。访问者不需要 GitHub 账号。

免费 GitHub 账号使用公开仓库；网页默认公开。发布前若仓库已有网站，应先核对现有 Pages 配置。

## 运势更新方式

GitHub Pages 只能托管静态文件，因此由 GitHub Actions 联网读取星座乐、核验北京时间的当天日期，并把四项文字提示、幸运信息写入 `site/horoscope.json` 后发布。页面会显示“定时更新”，不表示每次访问都实时抓取。

计划每天北京时间 00:17、02:17、08:17、14:17 更新；定时工作流可能排队延迟。公开仓库连续 60 天没有活动时，GitHub 可能自动停用定时工作流，需要在 Actions 中重新启用。可随时手动运行补更。

来源抓取失败不会阻止奶茶功能发布。页面不会把旧日期当作今天；只允许明确标注地展示当天已获取的浏览器缓存。源网站版式改变时可能需要调整解析器。

## 本地预览

在仓库目录运行 `python3 scripts/update_horoscope.py`，再运行 `python3 -m http.server 8765 --directory site`，打开 http://localhost:8765/ 。需要 Python 3.9+、curl。

## 随机偏好

在原有店铺均衡的基础上，霸王茶姬、名称含苹果、名称含茉莉或伯牙绝弦的单品，每命中一项增加 25% 的抽签权重，叠加最多增加 50%。这是相对权重，不是固定中奖概率；实际概率随所选分类和上一杯结果变化。保留全部单品，正常避免连续抽中同一杯。偏好固定在代码中，不增加网页编辑控件。

伯牙绝弦的茉莉茶底参考：[霸王茶姬官方产品介绍](https://chagee.com.sg/zh-sg/product/fresh-milk-tea-series)。

## 店铺图标与运势文字

店名旁显示对应品牌 logo，图片嵌入网页，访问时无需请求图片网站。Logo 参考[品牌目录](https://www.nckfhsm.com/brands)，品牌名称与图形权利归各品牌所有。

运势不再展示百分比评分。每天核验白羊座原文日期后，读取综合、感情、事业、健康段落，按原文命中的主题选择简短的原创提示，分别展示为今日节奏、感情、工作、生活。这是基于原文主题的规则整理，不是逐字摘录或完整文章；未命中主题时提示读者查看原文，不编造预测。页面保留当天原文入口及幸运色、幸运数字。缓存版本已更新，旧版评分缓存不会继续使用。
